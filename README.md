# OpenEdge Manager (OEM) — starter

Self-hosted open-source-first edge fleet and flow management foundation.

## Start locally
Requirements: Docker Engine + Docker Compose plugin.

```bash
cp .env.example .env
docker compose up --build
```

- UI: http://localhost:5173
- API docs: http://localhost:8000/docs
- Health: http://localhost:8000/health
- MinIO console: http://localhost:9001

This is a development scaffold, not a production-ready Cloudera Edge Management replacement.
The visual editor and management API are starter implementations. The MiNiFi C2 adapter,
runtime compiler, real agent deployment, authentication, RBAC and mTLS are not yet complete.

**Important:** `/api/v1/agents/{id}/heartbeat` is an OEM development endpoint, NOT the
Apache MiNiFi C2 wire protocol. Do not point a production MiNiFi agent at it.

## Architecture
- React + React Flow: independent advanced flow designer
- FastAPI: management API
- PostgreSQL: persistent inventory, flow and deployment metadata
- Redis: future asynchronous job queue
- MinIO: future immutable runtime artifact store
- MiNiFi C++: intended initial edge runtime
- OEM canonical JSON DSL: source of truth; runtime-specific YAML generated by compiler

See `docs/` for specification, API, security and implementation plan.
